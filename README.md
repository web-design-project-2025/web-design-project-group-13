# 🥬 Lettuce Cook

**Lettuce Cook** is a recipe inspiration website designed for users seeking quick, convenient, and visually engaging meal ideas. With aesthetic imagery and brief descriptions, users can easily browse and discover new recipes without feeling overwhelmed.

## 🌟 Features

- View **popular and trending recipes** at a glance
- Browse by **meal category** (e.g., Dinner, All Meals)
- **Like and unlike recipes** across all pages
- Explore detailed **recipe pages** with ingredients, methods, and user reviews
- Use the **filter feature** to find recipes by specific ingredients
- **Search** for recipes by name or keywords
- Learn more about our mission on the **About Us** page

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (JS)
- JSON
- Web-storage API

## 🖼️ Usage

- Scroll down the homepage to discover **trending recipes**
- Use the **Meals menu** to filter by meal categories
- Click on a **recipe card** to read more about its ingredients and preparation method
- Use the **heart icon** to like or unlike recipes — your favorites are saved automatically
- Try out the **search bar** or use **ingredient filters** to find recipes that suit your needs
- Visit the **About Us** page to learn more about the team behind Lettuce Cook
